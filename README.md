# A Beautiful Mess of Me

Shriya Shrivastav's personal portfolio. *I make messy things feel simple.*

A scrapbook in five rooms: Things That Made Me, Inside My Head, Things I Made, Beautiful Failures and Still Becoming. Plus a Shuffle My Brain button and a guestbook.

## Run it
It's a single static page. Open `index.html` in a browser, or deploy the folder to Vercel as-is (no build step).
